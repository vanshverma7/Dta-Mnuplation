When a file is sent from one place to another, sometimes it can get slightly damaged or altered along the way.
A checksum is just a way of checking that what arrived is exactly the same as what was sent. Before sending, a number is calculated from the file. After receiving, the same calculation is done again. If both numbers are the same, the file is fine. If not, something went wrong.
